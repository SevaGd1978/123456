# РейсОфис

Веб-кабинет экспедитора и разбор того, как улучшить типичный десктопный TMS (на примере поставки TransTrade: лицензия, журнал инноваций, `config.ini`, обмен с 1С, карточка «интернет-сервера»).

Это **не модификация чужой программы** и не её исходный код. Лицензия TransTrade прямо запрещает декомпиляцию и правку файлов программы. Здесь — отдельный открытый прототип, который закрывает слабые места, видимые по конфигурации и changelog.

## Что было не так в поставке

1. **Секреты в открытом виде.** В `config.ini` лежали логин/пароль MySQL и FTP. Тот же FTP-пароль повторён в PDF панели REG.RU. Такой файл нельзя класть в git и нельзя держать на всех рабочих местах.
2. **Архитектура 2015 года.** Windows-клиент + платный shared-хостинг как «общая база» (149 ₽/мес). Для журнала заказов это хрупко: кодировки, обрывы связи, нет нормального веба.
3. **Обмен с 1С через `C:/...xml`.** Пути зашиты в ini. Один диспетчер, один диск C:, CP1251/XML без предпросмотра.
4. **Эвристика веса.** В инновациях не раз чинили перевод «если меньше 100 — это тонны». Для ЭТрН это источник брака.
5. **Большие справочники.** Поиск по ИНН и загрузка списков > 5000 строк чинили несколько релизов подряд.
6. **НДС 22%.** Ставка 2026 года правилась отдельно в УПД, 1С, счетах, актах.
7. **Vendor lock-in.** Демо на 10 заказов, код закрыт.

## Что делает РейсОфис

- Журнал на 1800 рейсов с виртуальной прокруткой и поиском по ИНН
- Заказ: тонны/кг явно, чеклист ЭПД, прицеп, срок оплаты, НДС 22% в копейках
- **Калькулятор себестоимости в каждом рейсе:** ЗП водителя ₽/км + «Платон» ₽/км + расход 35 л/100 км × цена литра
- **Километраж по пунктам погрузки и выгрузки** с бесплатных OSM Photon / Nominatim и **грузового** маршрута Valhalla (фура 16,5 м / 4 м / 20 т, дороги HGV; легковой OSRM не используется). Если карта недоступна — оценка по прямой × 1,25
- Справочники клиентов, перевозчиков, грузоотправителей и грузополучателей с проверкой ИНН
- **Подстановка названия и реквизитов по ИНН** из открытой выписки ЕГРЮЛ.org и (по желанию) бесплатного API Дадаты
- Печать счёта-заявки из браузера
- Обмен с 1С: UTF-8 XML, своё имя файла, предпросмотр, журнал операций
- Роли: директор / диспетчер / бухгалтер — без пароля базы в ini

## Запуск

```bash
npm install
npm test
npm run dev
```

Откройте http://localhost:5173

| Логин | Пароль | Роль |
| --- | --- | --- |
| `dispatcher` | `route` | Диспетчер |
| `director` | `office` | Директор |
| `accountant` | `ledger` | Бухгалтер |

Сборка: `npm run build` и `npm run preview`.

## Безопасность

Файлы с паролями хостинга **не включены** в репозиторий. Если они уже уходили на почту или в облако — смените пароль базы и FTP в панели хостинга.
