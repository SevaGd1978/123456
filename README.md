# Неподвижные опоры трубопроводов

Локальное приложение для подбора и расчёта неподвижных опор теплосетей: нагрузки, проверки по СП 16.13330, чертёж, 3D, спецификация и заказ.

Откройте `index.html` в браузере — сервер не нужен.

Отдельное приложение на Amvera (msk1, не затрагивает другие проекты):
https://opory-sevagd1978.msk1.amvera.tech/

## Что исправлено относительно исходного файла

- Осевое усилие: **N = γ·(Np + Nтр + Nк)** на компенсированном участке (по умолчанию). **Nt = α·E·F·Δt** считается справочно и входит в сумму только при флажке «Участок защемлён». γ = 1,2 по ТТ, снимается флажком.
- **Ry** берётся по толщине элемента (ряды СП 16 для С245 / С345)
- В 3D — **швы**, **фаски плиты**, технологический зазор 0,4…1,2 мм
- **Отмена** последних действий по проекту
- Комплект чертежей: **лист 1 — общий сборочный**, далее **подробные чертежи деталей** опоры (виды, размеры, развёртки, отверстия)
- Из заказа собираются **рабочие чертежи производства**: сборка и детали каждой опоры, раскрой листа, карты реза проката и комплектовочная ведомость

Программа помогает собрать расчёт и комплект документов, но не заменяет подпись ГИПа и выпуск РД.
