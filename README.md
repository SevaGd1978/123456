# Смена 20:00 — ежедневная проверка штрафов ГИБДД

Веб-приложение для автопарка: до 30 машин, вечерняя автоматическая проверка, журнал постановлений и уведомления о новых штрафах.

По умолчанию проверка запускается каждый день в **20:00 по Москве**. Это можно изменить.

## Что умеет

- хранит список автомобилей (госномер + СТС);
- каждый вечер сам проходит все включённые машины;
- показывает неоплаченные постановления, сумму и срок скидки 25 % (30 дней, ст. 32.2 КоАП РФ);
- умеет прислать сводку в Telegram или на webhook;
- не хранит пароли «Госуслуг» и не показывает посторонние персональные данные.

Официальный сайт ГИБДД требует капчу, а ГИС ГМП доступен организациям по договору. Поэтому в комплекте два режима:

| `FINES_PROVIDER` | Что делает |
| --- | --- |
| `demo` | Учебные постановления, чтобы сразу увидеть панель на 30 машинах |
| `http` | Запросы к **вашему** легальному API (`FINES_API_URL?plate=&sts=`) |

## Запуск

Нужен Node.js 20+.

```bash
cp config/vehicles.example.json config/vehicles.json
cp .env.example .env
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

В примере уже 30 машин. Замените госномера и СТС на свои в панели «Список машин» или в `config/vehicles.json`.

Разовая проверка без браузера:

```bash
npm run check
```

## Переменные окружения

См. `.env.example`. Главные:

- `CHECK_TIME=20:00` — ежедневный запуск;
- `TIMEZONE=Europe/Moscow`;
- `FINES_PROVIDER=demo` или `http`;
- `FINES_API_URL` / `FINES_API_TOKEN` — если используете свой API;
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — вечерняя сводка;
- `WEBHOOK_URL` — POST JSON на ваш URL;
- `API_TOKEN` — если задан, все `/api/*` требуют `Authorization: Bearer …`.
