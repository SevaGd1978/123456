# АвтоСлед

Учебное веб-приложение для проверки автомобиля по открытым данным.

- Поиск публичных записей владельцев-организаций по госномеру.
- Расшифровка VIN через официальный открытый API [NHTSA vPIC](https://vpic.nhtsa.dot.gov/).
- Источник и дата публикации у каждого результата.
- ФИО, адреса и контакты частных владельцев не собираются и не показываются.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

## Тесты

```bash
npm test
```

## Подключение реальных источников

Файл `data/public-records.json` содержит только явно помеченные демонстрационные
записи. Для рабочего использования замените его адаптером официального открытого
реестра вашей страны. Добавляйте только записи, лицензия и правовой режим которых
разрешают повторную публикацию.
