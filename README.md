# Семейный Бюджет (Family Budget Management App)

Современное веб-приложение для расширенного ведения и совместного контроля бюджета семьи.

## Основные возможности:
- **Семейные счета и кошельки**: поддержка наличных, банковских дебетовых и кредитных карт, накопительных счетов и инвестиций с автоматическим обновлением баланса.
- **Учет членов семьи**: привязка доходов и расходов к конкретным членам семьи (отец, мать, дети и др.) с индивидуальной аналитикой трат.
- **Категории доходов и расходов**: гибкая система категорий с цветовыми маркерами и иконками.
- **Месячные бюджеты и лимиты**: установка лимитов расходов по категориям с визуальным трекером прогресса и предупреждениями о перерасходе.
- **Семейные финансовые цели и копилки**: совместное накопление средств на крупные покупки, отпуск или подушку безопасности с отслеживанием прогресса в процентах.
- **Глубокая аналитика**: интерактивные графики динамики доходов/расходов по месяцам, структура расходов по категориям (Pie Chart) и распределение расходов среди членов семьи.
- **История операций**: фильтрация по типу операции, счету, категории, члену семьи и текстовый поиск.
- **Темная и светлая темы**: современный стильный дизайн с переключением темы.

---

## Архитектура и технологии
- **Backend**: Python 3.12, FastAPI, SQLAlchemy 2.0, SQLite, Pydantic v2, Pytest.
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Recharts, Lucide Icons.

## Запуск приложения

### 1. Запуск всего приложения одной командой:
```bash
./start.sh
```

### 2. Запуск вручную по компонентам:

#### Бэкенд:
```bash
cd backend
pip install -r requirements.txt
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```
Документация Swagger/OpenAPI доступна по адресу: `http://localhost:8000/docs`.

#### Фронтенд:
```bash
cd frontend
npm install
npm run dev
```
Веб-интерфейс доступен по адресу: `http://localhost:5173`.

---

## Тестирование
Для запуска автоматических тестов бэкенда:
```bash
python3 -m pytest backend/test_main.py -v
```

Для проверки сборки фронтенда:
```bash
cd frontend && npm run build
```

## Развертывание на Amvera Cloud

Проект полностью настроен для публикации в облаке **Amvera Cloud**:
- Настроен многоэтапный `Dockerfile` (сборка React Vite фронтенда и упаковка с FastAPI бэкендом).
- Добавлен конфигурационный файл `amvera.yml` (и `amvera.yaml`).
- Настроено постоянное хранилище `persistenceMount: /data` для сохранения базы данных SQLite (`family_budget.db`) между перезапусками контейнера.
- Контейнер слушает порт `80`.

### Шаги для деплоя в Amvera Cloud:
1. Зарегистрируйтесь / войдите в личный кабинет на [amvera.ru](https://amvera.ru).
2. Нажмите **«Создать проект»** (тип: **Приложение**).
3. Выберите способ загрузки кода:
   - **Через GitHub**: привяжите репозиторий `SevaGd1978/123456` (ветку `main` или текущую ветку PR).
   - **Через Git Amvera**: добавьте remote Amvera в ваш локальный репозиторий и выполните `git push amvera main`.
4. На этапе выбора конфигурации Amvera автоматически обнаружит `amvera.yml` и `Dockerfile`.
5. Убедитесь, что в разделе **«Конфигурация»**:
   - Окружение: **Docker**
   - Порт контейнера: **80**
   - Постоянное хранилище: `/data` (для сохранения базы данных)
6. Нажмите **«Завершить»** / **«Собрать»**.
7. После завершения сборки перейдите по предоставленному Amvera доменному адресу `https://<ваш-проект>.amvera.io`.
