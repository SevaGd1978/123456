Исходные данные

Осевое усилие на опору

Сумма составляющих по типовым ТТ тепловых сетей. По умолчанию участок считается компенсированным: N = γ·(Np + Nтр + Nк), γ = 1,2. Nt = α·E·F·Δt показывается справочно и входит в сумму только при флажке «Участок защемлён». Np = p·A — распор внутреннего давления; Nтр = μ·q·L — трение на участке подвижных опор; Nк — неуравновешенная реакция компенсаторов (задаётся).

Подбор конструкции

Прогон всех типов опор при заданных нагрузках и текущем прайсе. Сравнение по массе, стоимости и результатам проверочного расчёта.

Калькуляция стоимости

Чертёж формируется по расчётным размерам: 3 вида, размеры, позиции, ведомость параметров, технические требования, основная надпись по форме 1 ГОСТ 2.104. DXF выгружается в миллиметрах 1:1 (слои ОСНОВНАЯ / ТОНКАЯ / ШТРИХОВАЯ / ОСЕВАЯ / РАЗМЕРЫ / ТЕКСТ). Обязательно проверьте чертёж перед изготовлением.

Вращение — перетаскивание мышью; масштаб — колесо или «щипок»; перенос — Shift+перетаскивание или средняя кнопка; сброс вида — двойной щелчок. Модель строится по тем же расчётным размерам, что и чертёж: швы, фаски плиты, технологический зазор до трубы. Трубопровод показан условно — для ориентирования опоры.

Комплект: спецификация, ведомость материалов, ведомость швов, проверочный расчёт, калькуляция.

Из заказа собирается комплект на производство: сборочный чертёж каждой опоры, раскрой листа с марками деталей, карты реза проката и комплектовочная ведомость.

Прайс-лист и нормы

Цены материалов — за тонну; сварка — за метр шва по катету; сверление — за отверстие; окраска — за м²; сборка — за кг металлоконструкции. Значения сохраняются в браузере и в файле проекта.

Что считает приложение

  1. Подбор размеров элементов опоры по заданным нагрузкам (N — осевое, Q — вертикальное, S — боковое, M — момент) с округлением до стандартных толщин листа и катетов швов.
  2. Проверочные расчёты по СП 16.13330.2017: угловые швы на срез по металлу шва и по границе сплавления (βf = 0,7; βz = 1,0; lw = Σl − 10·n), изгиб косынок и щитов, изгиб свеса опорной плиты, растяжение полосы хомута, болты (растяжение, срез, трение), ограничение kf ≤ 1,2·t.
  3. Масса и спецификация: детали собственного изготовления (лист, полоса, уголок, швеллер, двутавр, труба, круг) и стандартные изделия (болты, гайки, шайбы по ГОСТ 7798-70, 5915-70, 11371-78), заготовки и развёртки.
  4. Стоимость: материалы с коэффициентом раскроя, сварка (по длине швов и катету), термическая резка, сверление, антикоррозионное покрытие, сборка, накладные расходы, прибыль, НДС.
  5. Документы: рабочий чертёж (3 вида, размеры, позиции, техтребования, основная надпись по форме 1 ГОСТ 2.104), спецификация, ведомость материалов, ведомость швов, проверочный расчёт, калькуляция, сводная ведомость заказа; выгрузка в SVG, DXF R12, XLSX, CSV, печать/PDF.
  6. Рабочие чертежи производства из заказа: сборочный чертёж каждой позиции, раскрой листового проката (MaxRects, зазор реза 5 мм, кромка 10 мм, поворот 90°), карты реза полосы / уголка / швеллера / трубы, комплектовочная ведомость деталей и метизов с марками «обозначение/позиция». Кнопка на вкладке «Заказ».
  7. 3D-вид: объёмная модель опоры по тем же расчётным размерам с вращением, масштабом, пресетами видов и режимами показа трубопровода (сплошной / полупрозрачный / скрытый); экспорт PNG и печать. Рендеринг собственный (z-буфер, отсечение обратных граней) — без внешних библиотек и без доступа в интернет. На модели показаны угловые швы (катет по расчёту) и фаски кромок плиты; зазор «опора–труба» принят технологический (около 0,5…1,2 мм), без искусственного увеличения. Разделка кромок под сварку условная (равнокатетный шов).

Типы опор

  • НО-Х — хомутовая (аналог Т11 / ТС-659, ТС-669): хомут из полосы, косынки с вырезом по хомуту, опорная плита. Осевое усилие — сварным швом по контуру хомута либо трением.
  • НО-Д — двухупорная (лобовая) (аналог Т4 / ТС-660): продольное ребро + поперечные косынки + опорная плита.
  • НО-Щ — щитовая (аналог Т8, Т9 / ТС-666, ТС-667): два щита с полукруглым вырезом по трубе, косынки, опорная плита.
  • НО-Ч — четырёхупорная (аналог Т5 / ТС-661): два продольных упорных ребра, приваренных к трубе по касательной, и две поперечные косынки.
  • НО-ХК — хомутовая с корпусом (аналог ТС-670, Дн 57–377): листовой корпус-лоток с упорами под хомутом; для труб в ППУ изоляции — сварка к трубе не требуется.
  • НО-БГ — бугельная с корпусом (аналог ТС-671, Дн 377–1420): корпус, бугели на шпильках, упоры; для труб в ППУ изоляции больших диаметров.
  • НО-П — элемент неподвижной опоры в ППУ изоляции (ЭНО) по ГОСТ 30732-2006/2020: стальной патрубок с несущей плитой (базовые размеры — по таблице стандарта), изоляция ППУ, защитная оболочка ПЭ или оцинкованная. Плита заделывается в монолитный ж/б щит (серии 313.ТС-002.000, 313.ТС-008.000). Основной вид неподвижных опор для бесканальной прокладки тепловых сетей в ППУ.

Корпусные опоры (НО-ХК, НО-БГ) и ЭНО предназначены для трубопроводов в ППУ изоляции: они не требуют сварки на трубе и не нарушают изоляционный контур. Для ЭНО контролируется нагрузка относительно справочного Pmax по таблице ГОСТ 30732.

Импорт позиций из Excel / CSV

На вкладке «Заказ» кнопка «Импорт из Excel / CSV…» загружает ведомость опор и добавляет все строки в заказ одним действием (после проверки таблицы-превью). Поддерживаются файлы .xlsx (первый лист книги) и .csv (кодировки UTF-8 с BOM и без, Windows-1251, UTF-16; разделители «;», «,» или табуляция). Кнопка «Шаблон для заполнения» скачивает готовый файл-образец. Обрабатывается до 500 строк.

Первая непустая строка файла — заголовки; колонки распознаются по названию (регистр, пробелы и дефисы не важны):

  • Тип — НО-Х / НО-Д / НО-Щ / НО-Ч / НО-ХК / НО-БГ / НО-П, латинские идентификаторы (clamp, tee, shield, thrust, clampcase, yoke, ppu) или аналоги серий (ТС-659…ТС-671, Т4, Т5, Т8, Т9, Т11, ППУ / ЭНО);
  • Ду — условный диаметр, или dн — наружный диаметр трубы, мм; Стенка, мм (необязательно);
  • N — осевое, Q — вертикальное, S — боковое усилие, кН; M — момент, кН·м;
  • Изоляция, мм; Сталь — Ст3сп5 / С245 / 09Г2С (С345); Кол-во, шт.; Наименование — произвольный текст.

Необязательные колонки можно опускать. Если диаметр или стенка не входят в сортамент или диапазон типа, в превью они отмечены предупреждением и подставлен ближайший допустимый типоразмер. Строки с нераспознанным типом пропускаются.

Нагрузки и стали

  • Осевое усилие: N = γ·(Np + Nтр + Nк) на компенсированном участке. Nt = α·E·F·Δt считается всегда, но входит в сумму только если участок защемлён (флажок). Np = p·A, Nтр = μ·q·L (масса трубы, воды и ППУ), Nк — реакция компенсаторов. Коэффициент γ = 1,2 включён по умолчанию и снимается флажком.
  • Ry берётся по толщине элемента из рядов СП 16.13330 для С245 / Ст3сп (245 / 240 / 230 / 220 МПа при t ≤ 10 / 20 / 40 / >40 мм) и С345 (335 / 320 / 300 / 280 МПа). Rwf / Rwz — для электродов Э46 / Э50.
  • Геометрия типовых конструкций задана параметрически и сверяется со справочными Pmax серии / ГОСТ 30732. Перед изготовлением размеры нужно проверить по действующему альбому и рабочей документации проекта.
  • Программа помогает собрать расчёт и комплект документов, но не заменяет подпись ГИПа и выпуск РД. Ответственность за принятые решения — на инженере.
