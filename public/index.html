    Как подключить платный API

    Бесплатных 200 запросов не хватит на 30 машин каждый вечер. Нужно около 900 запросов в месяц.

    API-CLOUD — для автопарка

    1. Откройте тарифы и документацию штрафов.
    2. Напишите на support@api-cloud.ru: нужны методы fines, около 900 запросов/мес, цель — мониторинг своего автопарка, реквизиты ООО или ИП и название ЭДО.
    3. Дождитесь регистрационного кода (до 7 рабочих дней). Ключ копируется в кабинете.
    4. В файле .env укажите:
    FINES_PROVIDER=cloud
CLOUD_API_TOKEN=ваш_токен

    Ориентир: минимальный платёж 700 ₽/мес при < 2000 запросов плюс оплата успешных запросов. Актуальные цены — на сайте API-CLOUD, это не оферта.

    API Assist — платный лимит

    1. Напишите на support@api-assist.com: нужен лимит от 900 запросов/мес.
    2. Полученный ключ пропишите так:
    FINES_PROVIDER=assist
ASSIST_API_KEY=ваш_ключ

    Документация: api-assist.com/api/fines. Цена платного тарифа по запросу.
